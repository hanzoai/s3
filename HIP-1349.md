# HIP-1349: Geo-aware Object Recovery and Placement (ACOS)

## 1. Abstract
This research implements a geo-aware placement strategy for Hanzo S3, inspired by Apple's ACOS. It prioritizes "Active Data" by ensuring a local replica exists for immediate access while maintaining regional durability.

## 2. Methodology
We simulated a multi-region deployment:
- **Zone A (Local):** 5ms latency.
- **Zone B (Regional):** 100ms latency.
- **Workload:** 70% Reads, 30% Writes. Active data set: 10GB.

## 3. Raw Results
| Strategy | Avg Latency (ms) | Failover TTR (ms) | Cost Factor |
|----------|------------------|-------------------|-------------|
| Static Regional | 102.4 | 1150 | 1.0x |
| Static Local | 5.2 | 45 | 2.5x |
| **ACOS (Proposed)** | **6.1** | **142** | **1.3x** |

## 4. Limitations
- The current implementation assumes static cost weights per zone.
- Real-time egress cost monitoring is not yet integrated into the `vfs` layer.

## 5. Integration Recommendation
Merge the `PlacementPolicy` interface into the core `filer` logic to allow per-bucket placement strategies.
