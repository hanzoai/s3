# HIP-1349: DisCoGC Implementation for Volume Management

## Abstract
Introduce economic-aware garbage collection (DisCoGC) to Hanzo S3 to reduce Write Amplification (WAF) and extend SSD lifespan.

## Specification
1. **Metric Collection:** Volume servers must track `LiveBytes` vs `TotalBytes` per volume.
2. **Policy Engine:**
   - `Mode Compaction`: (Default) Traditional copy-on-vacuum.
   - `Mode Discard`: If `LiveBytes / TotalBytes < config.DiscardThreshold`, delete volume.
3. **Safety Mechanism:** Discard mode is only permitted if the volume belongs to an EC-enabled storage class or has a replication factor > 1.

## Metrics for Success
- Physical WAF < 1.10 in high-churn workloads.
- Zero data loss in EC-sharded buckets during discard events.
